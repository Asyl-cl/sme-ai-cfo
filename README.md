# ИИ-финдиректор для МСБ Тараза

Telegram-бот и дашборд для малого бизнеса: владелец загружает продажи (CSV/Excel), банковскую выписку или фото накладной
и получает **конкретные действия с суммой в тенге**. Трек хакатона «AI for SME & Local Business».

**Принцип:** числа считает код (`core/`, pandas), ИИ (`ai/`) только объясняет, отвечает на вопросы, читает накладные
и пишет тексты. Модель сама ничего не считает.

## Что получает предприниматель
- убыточные позиции и замороженные остатки (в тенге);
- прогноз закупок на неделю с учётом дней недели;
- предупреждение о кассовом разрыве (горизонт 21 день);
- должники с рейтингом риска и готовый текст напоминания (рус/каз, мягкий/настойчивый/последнее предупреждение);
- ответы на вопросы свободным текстом;
- распознавание фото накладной с внесением в остатки;
- анализ банковской выписки по категориям;
- «эффект»: сколько денег высвобождено и потерь сокращено (с оговоркой, что расчёт на тестовых данных).

Не входит в MVP: интеграции с 1С, Kaspi и банками, оплата, роли, собственные ML-модели (это дорожная карта).

## Запуск
Нужен Python 3.11-3.13 (на 3.14+ нет готовых сборок pydantic-core и pyarrow, установка зависает).
```
python -m venv venv
venv\Scripts\activate                 # Windows;  Linux/macOS: source venv/bin/activate
python -m pip install -r requirements.txt
copy .env.example .env                # Linux/macOS: cp .env.example .env, затем впишите ключи
python data/generate_data.py          # тестовые данные мини-маркета (если папки data/sample нет)
python scripts/check_setup.py         # проверка Python, .env, ключа ИИ и данных
python scripts/warmup.py              # прогрев кэша ИИ перед демо
python -m bot.main                    # бот
streamlit run dashboard/app.py        # дашборд
python -m pytest -q                   # тесты
```

### Настройки `.env`
| Переменная | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
| `LLM_PROVIDER` | `anthropic` (по умолчанию), `openai` (любой OpenAI-совместимый API) или `gemini` |
| `LLM_API_KEY` | ключ провайдера |
| `LLM_MODEL` | по умолчанию `claude-sonnet-5-5` (`claude-haiku-5-5` дешевле) |
| `LLM_BASE_URL` | только для `openai`; по умолчанию адрес Gemini |

Ключи хранятся только в `.env` (он в `.gitignore`), в коде их нет.

## Данные для показа жюри
В `data/demo/` лежит вымышленный мини-маркет «Береке» с реальными названиями товаров и заложенными находками (убыточные
позиции, залежавшийся товар, кассовый разрыв, должники всех уровней риска), накладная в тенге (скан и «фото»), Excel для
загрузки и готовая таблица-отчёт `jury_report.xlsx`. Включение: `DEMO_DATA=data/demo/` в `.env`. Подробности и сценарий
показа: `data/demo/README.md`.

## Команды бота
`/demo`, загрузка `.csv`/`.xlsx`, `/report`, `/order`, `/debts`, `/effect`, `/bank`, `/balance <сумма>`,
`/remind [ru|kk] [настойчивый|последнее]`, фото накладной, вопросы текстом, кнопки-меню после отчёта.

## Форматы файлов (колонки)
- продажи: `date, sku, name, qty, price, cost` (category по желанию);
- остатки: `sku, qty`; долги: `client, amount, due_date` (`issued_date`, `paid` по желанию);
- плановые платежи: `date, name, amount`; банковская выписка: `date, description, amount` (расходы со знаком минус).

Русские и казахские названия колонок, `;` и запятая как разделители, даты `дд.мм.гггг`, заголовок не в первой строке,
несколько листов Excel распознаются автоматически.

## Архитектура
Telegram → `bot/` (aiogram 3) ↔ `dashboard/` (Streamlit) → `core/` (расчёты) → `ai/` (LLM) → `data/` (CSV/JSON).
Модули `core/`: `metrics` (маржа, ABC, убыточные позиции, мёртвый сток), `forecast` (закупки), `cashflow`
(грубый прогноз остатка денег), `debts` (риск по дням просрочки), `bank`, `effect`, `invoice`.

## Надёжность на демо
- Сбой ИИ не роняет бота: берётся сохранённый ответ из `data/llm_cache.json`, иначе показываются посчитанные цифры
  (для напоминаний: шаблонный текст). Кэш можно коммитить; после пересоздания `data/sample` прогрейте его заново.
- Все обработчики бота проверены тестами через настоящий диспетчер aiogram (команды, файл, фото, кнопки).

## Честные оговорки
Данные синтетические; кассовый прогноз грубый (не учитывает сезонность и возврат долгов); ИИ не даёт налоговых
и юридических заключений; цифры накладной нужно проверять вручную.
